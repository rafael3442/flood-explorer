# Flood explorer

Four floods on ungauged Portuguese catchments and what drove each model's streamflow:
the paper's TFT (Francisco et al., 2026, J. Hydrol. 681, 136642), δHBV, δHBV-TFT with
ERA5-Land and with MSWX forcing, and the paper's calibrated HBV. Each network is the
repetition with the best spatial-validation NSE in its fold.

Open it at https://rafael3442.github.io/flood-explorer/

`index.html` is generated by `src/event_explorer.py` and `src/export_pages.py` in the
dHBV_Portugal_TFT project; edit those, not this file.
